# Лабораторные работы по дисциплине «Прикладные задачи машинного обучения»

Тема ВКР: «Исследование надёжности методов прогнозирования долгосрочной ценности пользователей и её
прокси-оценки на примере сервиса доставки еды».

| Папка | Лабораторная |
| --- | --- |
| [`lab1_llm`](lab1_llm) | 1. Большие языковые модели: сегментация пользователей по будущей ценности в zero-shot и few-shot |
| [`lab2_multimodal`](lab2_multimodal) | 2. Мультимодальные модели: профиль, ряд активности, регион, картинка ряда и текст |
| [`lab3_marl`](lab3_marl) | 3. Мультиагентное обучение с подкреплением: портфель из отраслевых ETF, BenchMARL |
