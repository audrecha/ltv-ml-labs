# Лабораторная работа 3. Мультиагентное обучение с подкреплением: портфель из отраслевых ETF

Кооперативная многоагентная среда управления портфелем на открытых дневных котировках (Yahoo Finance).
Четыре агента распределяют деньги внутри своих секторов, пятый задаёт долю капитала в рынке, остаток лежит в кэше
под ставку 3-месячных векселей США. Решение раз в неделю, награда общая: доходность после издержек 10 б. п.
со штрафами за риск и за долю одной бумаги больше 25%. Алгоритмы — из BenchMARL: MAPPO, IPPO, MASAC, ISAC, QMIX,
VDN, IQL, MADDPG; бейзлайны — одноагентный PPO и равные веса. Перенос без дообучения — на акции компаний
доставки еды. Не является инвестиционной рекомендацией.

| Файл | Что делает |
| --- | --- |
| `download_data.py` | скачивает OHLCV и ставку ^IRX через yfinance |
| `features.py` | недельные признаки только из прошлого, аудит данных, панели |
| `env.py` | среда (TorchRL EnvBase, векторизованная по эпизодам) |
| `task.py` | подключение среды к BenchMARL |
| `train.py` | обучение одного алгоритма с одним seed и оценка политики по периодам |
| `run_v2_stage1.sh`, `run_v2_pipeline.sh` | все запуски: основная серия, 3 млн шагов для лучших, абляции |
| `metrics3.py` | Sharpe и Sortino сверх ставки, просадка, CVaR, оборот, нарушения, выбор по valid, бутстреп |

```
pip install benchmarl yfinance pandas pyarrow matplotlib
python download_data.py && python features.py
bash run_v2_stage1.sh && bash run_v2_pipeline.sh
```

Котировки Yahoo Finance — для личного и исследовательского использования, в репозиторий не входят.
